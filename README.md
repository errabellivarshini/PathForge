# SkillShift (Node.js + SQLite)

## Run locally

1. Install deps:
   - `npm install`
2. Start server:
   - `npm run dev`
3. Open:
   - `http://localhost:3000`

The SQLite DB file is stored at `data/skillshift.sqlite`.

## Note

- This project uses SQLite only (no MySQL / no MySQL Workbench required).
- To view the DB, open `data/skillshift.sqlite` in DB Browser for SQLite, or use the `sqlite3` CLI.
