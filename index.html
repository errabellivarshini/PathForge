      Lesson 4: useContext API

      What You'll Learn

      In this lesson, we'll explore the useContext hook, which allows you to access context values directly in your components without wrapping them in a Consumer component. We'll cover:

      • Understanding React Context API
      • Creating and providing context
      • Consuming context with useContext
      • Best practices and performance considerations
      • Real-world examples and use cases

      Key Concepts

      const value = useContext(MyContext);

      Accepts a context object (the value returned from React.createContext) and returns the current context value for that context.

      Exercise

      Create a theme context that allows components to access the current theme (light/dark) and a function to toggle it. Implement a theme provider component and use the useContext hook in several components to access and display the current theme.

      Pro Tip

      When using context, try to keep your context values as minimal as possible. If you find yourself passing many unrelated values through a single context, consider splitting them into multiple contexts.
